# Basic Calculator

This is a simple web-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition (+), subtraction (−), multiplication (×), and division (÷)
- Responsive and modern UI
- Keyboard support for all operations
- Clear (AC) and Delete (DEL) functions
- Handles floating point numbers and prevents invalid input (e.g., multiple decimals)

## Usage

1. Open `task3.html` in your web browser.
2. Use the on-screen buttons or your keyboard to perform calculations.
3. AC clears all input, DEL deletes the last digit, and = computes the result.

## Keyboard Shortcuts

- Numbers and `.`: Input digits and decimal point
- `+`, `-`, `*`, `/`: Operators (use `*` for × and `/` for ÷)
- `Enter` or `=`: Calculate
- `Backspace`: Delete last digit
- `Escape`: Clear all
